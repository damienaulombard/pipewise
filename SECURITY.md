# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately
through GitHub instead: **Security → Report a vulnerability** on this
repository ([direct link](https://github.com/damienaulombard/pipewise/security/advisories/new)).

Include the version (`pipewise version`), the command you ran and, if you can,
a minimal configuration that shows the problem.

## Supported versions

Fixes go into the next release; there are no backports to older versions
before v1.0.
